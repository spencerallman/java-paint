# Java Painter

This project creates a simple click and drag painting tool that has different color options as well as a clear button. It was designed using the Java programming language.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Install Java on your computer
2. Using VS Code or another IDE, create a new Java project

Instructions for using the software:

1. Run the code on the main class (PaintApp.java)
2. When a blank white window appears, click and drag your mouse on the screen to draw a black line.
3. Paint as you please, and feel free to change the color with the color button, or clear the canvas with the clear button when finished.
4. To end the program, close canvas window.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:
